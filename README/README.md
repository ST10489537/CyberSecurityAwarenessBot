# CyberSecurityAwarenessBot

## Description
This is a C# console chatbot that helps users learn about cybersecurity.

## Features
- Voice greeting (WAV file)
- ASCII art display
- User interaction with name
- Cybersecurity responses
- Input validation
- Typing effect

## How to Run
1. Open project in Visual Studio 2026
2. Build the solution
3. Run the application

## Requirements
- .NET 6 or later
